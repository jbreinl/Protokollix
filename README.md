# Protokollix 📊

**Protokollix** is a lightweight desktop application for rapid data evaluation, interactive plotting, and automated error propagation—optimized for undergraduate physics laboratory courses and scientific reports, designed specifically to streamline data analysis.

## Installation

For detailed step-by-step instructions, please refer to the [Installation Guide on our documentation page](https://jbreinl.github.io/Protokollix/#installation--download).

> [!NOTE]
> **Windows Users**:
> Microsoft Defender SmartScreen may prevent the app from opening on first launch. To launch it anyway, please [follow these instructions](https://jbreinl.github.io/Protokollix/#note-for-windows-users-smartscreen).

> [!NOTE]
> **macOS Users**:
> macOS may block the app on first launch (*"Apple cannot check it for malicious software"* or *"App is damaged"*), because Protokollix is an open-source project without a paid Apple Developer certificate. See [Bypassing macOS Gatekeeper](https://jbreinl.github.io/Protokollix/#important-notice-for-macos-users-gatekeeper-warning) for a quick workaround.
